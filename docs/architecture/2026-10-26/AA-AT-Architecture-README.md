# AA-AT — HLD و LLD معماری

این بسته، معماری **پیاده‌سازی‌شده** را از **وضعیت عملیاتیِ مشاهده‌شده در یک زمان مشخص** جدا می‌کند. HLD برای مرور اجرایی و LLD برای بازبینی مهندسی است. هر دو فقط مستندات شاخهٔ پژوهشی‌اند و هیچ فایل یا سرویس معاملاتی را تغییر نمی‌دهند.

[نسخهٔ دوصفحه‌ای PDF برای ارائه](AA-AT-Architecture.pdf) نیز آماده است.

فایل‌های SVG از [render_architecture.py](render_architecture.py) تولید می‌شوند. برچسب‌های فارسی با جهت راست‌به‌چپ و فونت نصب‌شدهٔ Tahoma/Segoe UI رسم شده‌اند؛ هیچ فونتی در مخزن کپی نشده است. خطوط پیوسته، ارتباط پیاده‌سازی‌شده با شاهد کد؛ خطوط‌چین، مسیر پژوهشی یا ارتباطی با وضعیت عملیاتی نامعلوم را نشان می‌دهند. رنگ خاکستری برای مسیرهای مسدود یا تأییدنشده است. وجود پیکان پژوهشی به معنی اتصال به مسیر ارسال سفارش نیست.

**مبنای سیاست ریسک:** متن قدیمی درخواست، سقف ریسک باز ۲٪ را نام می‌برد. پیکربندی مؤثر نسخهٔ ۴ که در heartbeat محلی با hash تطبیق شده، پنج جایگاه سراسری، سقف ۱۰٪ ریسک باز و معلق، توقف زیان روزانه ۵٪ و توقف افت اکوئیتی از قله ۱۰٪ را دارد. برای نمادهای غیرطلا سقف اولیهٔ هر معامله ۰٫۲۵٪ از سهم مجازی کارگر است. برای XAUUSD سقف، کمینهٔ ۱۰ دلار، ۱٪ اکوئیتی حساب و فضای باقیماندهٔ توقف‌های روزانه/قله است. این مقادیر در نمودار ثبت شده‌اند؛ هیچ تغییر ریسک در این کار انجام نشده است. مقدار ۱۰٪، احتمال برخورد به SL را ذاتاً تغییر نمی‌دهد.

**وضعیت در ۲۰۲۶-۱۰-۲۵ حدود ۲۳:۰۶ UTC:** task معاملاتی و فرایند Python مربوط مشاهده شدند؛ heartbeat محلی `HEALTHY` و `demo_verified=true` را گزارش می‌کرد، S01–S05 فعال و S06–S18 مسدود بودند، ۳۹۵ معاملهٔ بسته و صفر جایگاه اشغال‌شده ثبت شده بود. این یک مشاهدهٔ زمان‌دار از وضعیت broker-reconciled محلی است، نه تضمین فعالیت اکنون یا مشاهدهٔ مستقل جدید از بروکر. داشبوردهای loopback در پورت‌های ۸۷۶۵ و ۸۷۷۵ در زمان بررسی listener داشتند. پل فرمان کارگران در heartbeat نسخهٔ عملیاتی اعلام نکرده بود؛ دکمه‌های مدیریتی را مسیر فعال نمایش ندادیم.

**پژوهش:** Graphify موجود ۳۰۴ گره و ۸۱۴ رابطهٔ معتبر دارد، اما snapshot آن متعلق به ۲۳ اکتبر و سیاست قدیمی‌تر است؛ بنابراین برای مقادیر مؤثر به کد و پیکربندی کنونی رجوع شده است. EA پژوهشی S04 کامپایل شده اما برابری زمان اجرای MQL5 هنوز تأیید نشده است. تستر MT5 جدا با خطای «حساب مشخص نشده» متوقف شده؛ هیچ backtest معتبر سه‌ساله یا دادهٔ تأییدشدهٔ XAUUSD در checkpoint پژوهشی ثبت نشده است. Market Status Engine و واردکنندهٔ تقویم اقتصادی پیاده‌سازی شده‌اند ولی منبع برنامهٔ بروکر یا رویداد اقتصادی معتبر هنوز وصل نیست.

این بسته طبق مشخصات نوشتاری سبک بصریِ تأییدشده (پس‌زمینه روشن، کارت‌های گرد و رنگ‌های دامنه‌ای) ساخته شد. **فایل خود اینفوگرافیک مرجع** در مسیرهای پژوهش و مخزن پیدا نشد؛ تطبیق دقیقِ پیکسلی با آن قابل‌ادعا نیست. خروجی PNGها پس از رندر مرورگری به‌صورت بصری برای جهت متن، برش و تداخل بررسی شده‌اند.

## بازتولید و امنیت

از Python محیط پژوهشی یا هر Python 3 سازگار اجرا کنید:

```powershell
python docs/architecture/2026-10-26/render_architecture.py
```

این اسکریپت فقط SVGها را در همان پوشه می‌نویسد و هیچ کد معاملاتی یا MT5 را import نمی‌کند. PNGها از SVG در مرورگر محلی headless با viewportهای ۱۸۰۰×۱۰۸۰ و ۲۴۰۰×۱۵۷۰ خروجی گرفته شده‌اند. شواهد و زمان‌های بررسی در [AA-AT-Architecture-Evidence.md](AA-AT-Architecture-Evidence.md) ثبت شده‌اند. شناسهٔ کاربر/رایانه، شماره حساب، کلید و مسیر credential عمداً از این بسته حذف شده‌اند. مسیرهای محلی در مستندات باید با `%USERPROFILE%` یا `[OS_USER]` نمایش داده شوند. تاریخچهٔ Git بازنویسی نشده است؛ اصلاح مستندات پیشین فقط روی این شاخهٔ پژوهشی است و به شاخهٔ عملیاتی merge نشده است.

`validate_architecture.py` اعتبار XML برداری، ابعاد و سلامت PNG، وجود برچسب RTL، ساختار پایهٔ Mermaid، سربرگ PDF و نبود مسیر کاربر OS را بررسی می‌کند. ابزار رسمی Mermaid CLI در این محیط در دسترس نبود و تلاش برای دریافت آن از رجیستری npm پاسخ نداد؛ بنابراین **رندر واقعی `.mmd` با parser رسمی تأیید نشده است**. خروجی‌های SVG/PNG مستقل به‌صورت بصری بررسی شدند.
